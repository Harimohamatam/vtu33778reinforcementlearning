# Vtu33778reinforcementlearning

Create a minimal interactive web app based on my existing RLHF vs DPO course project notebook.

The notebook implements a lightweight simulated language model, SFT baseline, RLHF training, DPO training, preference learning, gold reward evaluation, learned reward scores, KL divergence, and an independent judge.

Requirements:

Let users enter a text prompt and select SFT, RLHF, or DPO.

Generate a response using the same model logic as the notebook, if that code can be integrated.

Show the response and applicable evaluation metrics.

Include a comparison option for the three methods.

Reuse the notebook's actual code and experiment logic wherever possible.

Do not fabricate results or display fixed scores as live evaluations.

Do not claim the original trained models are connected unless they really are.

No personal details, download links, login, database, or unnecessary features.

Use a simple white-and-blue interface and minimal dependencies.

Keep the implementation as small as possible to conserve free credits.

If the notebook code is not available in this project, explain what code or model files are needed instead of creating a fake working simulation.
